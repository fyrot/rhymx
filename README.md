# Rhymx 
#### (...no logo yet, WIP)


Rhymx is a media player and library manager designed to help you conveniently organize a music collection of any size. Built on ElectronJS, Node.js, and countless other libraries, it's a cross-platform solution presented as a friendly application. 

Beyond its refined UI, the app also features a **"plugin" system** where you can link external libraries to lifecycle events in the app to export your listening history, connect external sources, and more. Plugins are written in JavaScript and should be bundled in a standalone ```.rhymx``` file. More information later on. 

The app *is* in a functional state, but there's always improvements to be made. 

## Features

**Extensive library indexing**: Load your music once and have it labeled with titles, artists, albums, art, etc. out of. the box. These tags can also be used as search queries.  

**Redesigned interface**: A relatively pleasing visual layout, intended to be fluent and reflective of the currently playing track. Check out the player bar at the bottom of the screen for at-a-glance track details.

**Custom synced lyrics support**: Include a ```.lrc``` file in your library to include synced lyrics for any track. See them in the app, timed to your music, when playing a song through the universal player bar. 

**Playlist management**: Create playlists and add tracks from your library to them!

**Plugins**: Point Rhymx's data to anything you can code to, or imbue the app itself with added functionality in a flexible JavaScript package that can be loaded at runtime. Per-plugin preferences can be customized in Rhymx as well. 

...and more to come (or to be mentioned 👀)!
